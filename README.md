# Full Stack Reviews Application

Полнофункциональное приложение для управления отзывами с системой модерации.

## Технологии

### Backend
- Go + Gin Framework
- PostgreSQL
- JWT авторизация
- GORM ORM

### Frontend
- React.js
- Material-UI
- React Router
- Axios

## Функционал
- Регистрация и авторизация пользователей
- Подтверждение email
- Создание и просмотр отзывов
- Система модерации
- Админ-панель
- Анонимные отзывы

## Запуск проекта

```bash
docker-compose up --build
Приложение будет доступно:

Frontend: http://localhost:3000
Backend API: http://localhost:8080
