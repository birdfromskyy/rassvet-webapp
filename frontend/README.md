# Frontend Rassvet

React-приложение собирается с помощью Vite. Рекомендуемая локальная версия
Node.js закреплена в `.nvmrc`; установка зависимостей должна выполняться через
воспроизводимый `npm ci`.

```bash
nvm use
npm ci
npm start
```

Основные проверки:

```bash
npm test
npm run build
```

Публичные переменные frontend должны начинаться с `VITE_`. Значение
`VITE_API_URL` встраивается в bundle при сборке и не должно содержать секреты.
